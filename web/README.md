# E.R.R.O. web

React + TypeScript on Vite. This is a static chat preview for Eric and Robin's
shared project. The composer and chat actions are disabled; there are no API
connections or message submission handlers.

Read [project context](../docs/project-context.md) before adding features.

```sh
npm ci
npm run dev
```

```sh
npm run lint
npm run build
```

Alternatively, run `docker compose up` from the repository root. See the
[root README](../README.md) for details.
