# Project context

Read `docs/project-context.md` before working on this repository. It records
E.R.R.O.'s founders, tentative direction, and current website requirements.

Keep the chat frontend inactive: no sending messages, API calls, AI integrations,
or backend unless the user explicitly changes that scope. Preserve the
distinction between possible future ideas and confirmed product decisions.

Run `npm run build` and `npm run lint` from `web/` for frontend changes. Check
responsive layout and disabled chat controls when changing the interface.
